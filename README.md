# 京王線 連続立体交差事業(笹塚〜仙川)3Dビューア

京王線 笹塚〜仙川間の連続立体交差事業(高架化)の完成後の姿を、ブラウザで見られる3Dで再現した**非公式**の制作物です。
高架橋・駅(公表されたデザインのイメージパースに合わせた外装)・線路と分岐器・架線・京王8000系/9000系の走行・
沿線の街並み(国土交通省 3D都市モデル PLATEAU)を描きます。

> 京王電鉄株式会社・東京都・国土交通省の公式のものではなく、承認や監修も受けていません。
> 完成後の姿は公表資料・地図・写真からの推定を含みます。

## 開き方

1. このリポジトリを手元に取る(GitHub の「Code」→「Download ZIP」など)。
2. `keio_elevated_3d.html` をブラウザ(Chrome・Edge・Safari・Firefox)で開く。
   - three.js を cdnjs から読むので、初回はインターネットに接続しておく。
   - 沿線の実際の建物・道路・緑地は `plateau_bldg.js`・`plateau_land.js`(同梱)を HTML と同じフォルダに置くと出る。
     無いときは模式の街で描く。
   - スマートフォンは横画面で。

## 操作

- ドラッグで移動、右ドラッグ(または Shift/Ctrl+ドラッグ)で回転、ホイール(2本指)で拡大・縮小。
- 画面下の縦断図の駅を押すと、その駅へ移る。
- 右のメニュー:全体俯瞰・運転モード(特急/各停を選んで下り線を運転)・列車追尾・自動旋回・列車走行・駅ラベル・踏切名・
  時刻(朝・昼・夕・夜)・季節(春・夏・秋・冬)。
- 運転モード:↓=力行側・↑=制動側・N=中立・E=非常ブレーキ(画面左下のボタンでも)。ドラッグで首を振る。
  駅の停止位置の前後1m に止まると扉が開く(特急は通過駅では開かない)。
