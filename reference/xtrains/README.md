# 井の頭線・世田谷線の車両(交差鉄道の車両)

- 2026-11(その3)利用者指示「井の頭線と世田谷線は前面と側面を画像検索し、京王8000系・9000系並みにリアルにして」→ 公表の諸元と文章からの推定の簡易な形を作った。
- 2026-11(その4)利用者指示「リアルさは期待した粒度の5%程しか実現されていない。井の頭線は1751編成を、世田谷線は304編成をモデルに再度リアルにして。
  この際、これまで京王8000・9000系に指示してきた内容・流れを洗い出して今回の作業に漏らさず適用して」→ **写真を画素で測り、8000・9000系と同じ作り
  (makeXCar。HTML の 9c章)で作り直した**。

寸法の表と測り方は `measured_1000.md`(京王1000系 1751F)・`measured_300.md`(東急300系 304F)。写真は同梱しない(Wikimedia Commons の写真を
測った値だけ)。検証は ⑱ `tools/verify_xcar.js`(形・扉と窓の並び・前面の部品・編成・車輪・停車中の扉の向き・300系の連接と折り返し)と、
⑦ `tools/verify_city.js` の 6.(台車が線路の上・左側通行・車輪・停車)。

## 推定(写真で確かめられなかった所)

- 1000系:台車中心(8000系と同じ ±6.88)・軸距・床下機器・冷房装置の長さ・側面の表示器と表示灯の位置・車内の座席の色。下りの 1758F は 1751F と同じ
  1・2次車・同じ色なので形は 1751F と同じとした(改造の有無は確かめていない)。
- 300系:床の高さ(0.80)・屋根の高さ(3.08)・2つめの扉より後ろの窓・前面の灯火の箱の大きさ・車体の色の16進。
