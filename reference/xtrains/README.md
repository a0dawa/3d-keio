# 井の頭線・世田谷線の車両(交差鉄道の車両)の寸法の根拠

2026-11 利用者指示「井の頭線と世田谷線は前面と側面を画像検索し、京王8000系・9000系並みにリアルにして」。
以前は箱を組んだ簡易の形だった。HTML の `XCAR`(寸法と断面)・`XCOL`(編成の色)・`xCarFaces()`(形)で作り直した。
写真は同梱しない。この作業環境からは画像を開けなかったので、**形は公表の諸元と文章の記述からの推定**(8000系・9000系のような
写真の画素の実測ではない)。写真があれば、8000系(`reference/keio8000_v4`)・9000系(`reference/keio9000`)と同じ手順で合わせられる。

## 検証

⑦(`verify_city.js` の 6. 交差鉄道)が、描いた車輪の頂点から軌間・台車の中心が線路の上・左側通行・停車を見る(形を作り直しても車輪の形と位置は以前のまま)。
⑪ が井の頭線のホームの上面を床(公表 1,150mm)の 5cm 下で見る。
