# 京王9000系 寸法の根拠(公表値と推定値の一覧)

`keio_elevated_3d.html` の諸元表 `K9`(9b章)の根拠。8000系(`reference/keio8000_v4/`)は利用者提供の
Blender モデルと編成写真の実測(60px/m)が根拠だが、9000系は**写真の実測がまだ無い**。
公表されている値・説明をそのまま使い、公表の無い寸法は 8000系の実測に寄せて推定した。

値を変えるときは、先にこの表を直してから `K9`(HTML)と検証(`tools/verify_car9.js` ⑭・
`tools/verify_k9render.js` ⑮ の REF)を直す。検証側の基準値は HTML から読まない。

## 2. 公表の説明(形・塗り分けに反映)

- 前頭部は乗務員扉までアイボリー塗装の普通鋼製、スカートも同色(Wikipedia)
- 正側面の腰部に京王レッドと京王ブルーの帯。8000系で窓上(幕板)にあった京王レッドの帯は無い(Wikipedia)
- 扉間に窓2枚、戸袋窓は廃止(2枚1組のサッシュレス1枚下降窓、一部固定)(Wikipedia)
- 前面は8000系に似るがやや直線的。行先表示器は中央扉の上、車号は向かって右の窓の上(ニコニコ大百科)
- ~~運転台の窓は側面まで回り込むパノラミックウインドウ(鉄道チャンネル)~~ → 前面写真(3b)では窓は前面の中で閉じ、角はアイボリー
- 前照灯・尾灯は前面窓の下(マイナビニュース:窓の下・灯火の上にラッピングがある)。前面写真(3b)では青帯の中
- 前面の表示器:更新車は種別・行先ともフルカラー LED(1台にまとめた形で描く)

## 3b. 前面写真の実測(2026-10。利用者提供の写真:9705 が踏切に近づく所、正面やや左から)

写真の中央(前面)を切り出し、**正面から見た平面**へ写し直した `ftex9.png`(150px/m、横 ±1.45m・縦 z 0.30〜3.75m)。
写し直しは `rectify_ftex9.py`(元の写真はリポジトリに入れていない。引数で渡す):

- 縦の目盛り:屋根の頂部(公表 3,620mm)と、中央の扉の枠の中心の幅(公表 610mm=34.5px)から 56.6px/m
- 横:前面は上から見て R10m の曲面で、写真は左に振っているので左右で縮みが違う。左右で対になる目印
  (扉の枠・窓の内縁・灯火の内端と外端・窓の外縁)を「実の |y| ↔ 中心からの画素」の折れ線で対応させた
- 右の窓の外縁より外は角に隠れて写っていない(灰で埋めた)

写し直した画像を画素の色で測った値(y=中心からの左右、向かって右が+。z=レール面から):

**利用者指示で写真の実測から変えた所**(2026-10):スカートの幅を1.225倍(脇の板 |y| 0.674〜1.139)、行先表示板を
表示板ごと1.15倍(|y|≤0.2415・z 3.194〜3.366)。車号は字形のまま描く(枠いっぱいに伸ばすと縦長になる)。
種別は2文字の間を空ける(「特  急」「各  停」)、行先の「新宿」も「新  宿」。
車号は少し右上へ、種別と同じ高さ(中心 z3.24)に:y 0.61〜0.95・z 3.175〜3.305。
識別灯は白の縦長で、種別の左 y −1.00〜−0.94・車号の右 0.99〜1.05(z 3.16〜3.32)。各停以外の種別で点く
(京王の呼び名は「識別灯」。実車は快速以上の種別で、通過駅のある区間に点ける。ここでは種別だけで決める)。

側面は柵越しで不鮮明だった。赤帯が窓のすぐ下にあることは前面の値と矛盾しないので、側面の帯も同じ高さにした
(側面の帯の太さは、編成写真があれば測り直す候補)。

## 4. 実測で直すときの手順(8000系と同じ要領)

1. 編成写真(山側・海側)を 60px/m に揃え、帯・窓・扉・幕板の小物の位置を測ってこの表に書き足す
2. 前面写真から、ガラス域・灯火・表示器・車号の位置を測る
3. `K9` と検証の REF(⑭⑮)を直し、`bash tools/verify_all.sh` を通す
