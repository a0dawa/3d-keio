## 位置の読み方

1. 事業案内図(PDF)を 400dpi で画像にし、地図の部分を切り出した(`annai_crop`。2315×2339 画素)。
2. 地図の道路の線を、PLATEAU の道路(`plateau_land.js`)を同じ向き・縮尺で描いた画像と FFT の相互相関で合わせた
   (拡大縮小 2.04・回転 −0.005rad。地図は北が上ではなく、右下の矢印が北)。
3. 赤い線(駅前広場の四角形と 154 の帯の6点)の中心を画素で読み、世界座標→緯度・経度にした。

## 中の配置(構想図からの推定)

構想図は南西の上空から北東を見た鳥瞰の絵で、寸法は書かれていない。ビューアは次のように置いた(数値は推定。HTML の `MEIDA.L` など):

- 駅前(北の辺から 10.5m):歩行者の広場と木の列(北から 5m)。
- 西の歩道 4.5m・南の歩道 4m・東の歩道(154 の側)。
- 時計回りのロータリー(左側通行で島を右に見る):車道の外形=北 10.5・東 12・南 4・西 4.5m 内。島=その内へ北 7・東 7・南 9・西 9m、
  角は半径 4m。島に大きな木と時計(絵の時計の柱)。
- 南の縁にバスの乗り場(バスは西向き)、西の縁にタクシーの乗り場(北向き。絵ではタクシーは島の北西に並ぶ)。
- 東の 154 へ出入りする取付道路:区画街路の公表の幅 21m・延長 12m を、車道 13m(東の辺の北東の角から 32〜45m)と両側の歩道 4m に。
  154 の西の歩道は口で切る。
- 絵の歩行者デッキ(改札の前から 154 を渡って広場へ降りる)は描かない:ニュースで「改札口付近から広場へはこの絵のように段差なく
  通路を作ることは難しいのではないか」と指摘され、区の現行の設計の形も分からないため。
