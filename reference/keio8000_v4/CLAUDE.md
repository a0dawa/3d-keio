動画「京王線高架化」（2026年9〜10月）のために作った京王8000系の車体（v4）を、
ほかの作業でも使えるように単体にしたもの。使い方・作業ルール・照合の方法をまとめる。
**作業を始める前に必ずこのファイルを読むこと。**

## 動かし方

Blender 4.2 の Python で動く。どちらでもよい。
- pip の bpy：`pip install bpy==4.2.0`（Python 3.11 が必要）→ `python3 スクリプト.py`
- Blender 本体：`blender -b --python スクリプト.py`

```python
import sys, math
sys.path.insert(0, "/path/to/keio8000_model")        # このフォルダ
import keio8000 as k8

k8.init()                                             # 材質と部品メッシュを作る（最初に1回。開き直したら再度）
tr = k8.build_train("下り特急", "8714F", kind="特急", dest="京王八王子", bound="down", crowd="light")
k8.place_straight(tr, front=(0, 0, 0), heading=math.pi)   # 先頭を原点に置き、-X へ進む向き
```

| 関数・定数 | 内容 |
|---|---|
| `init(font_path=None, trolley_height=4.9)` | 材質と部品メッシュを作る。フォントは 引数 → 環境変数 `KEIO8000_FONT` → 同梱 → OS の順に探す。`trolley_height` はパンタグラフの舟を上げる高さ（レール面から） |
| `build_train(name, formation, kind, dest, bound, crowd, collection, kind_color)` | 編成を組み立てて `Train`（`root`・`cars`・`collection`）を返す。`bound`：`"down"`＝下り（京王八王子方の車両が先頭）／`"up"`＝上り。`crowd`：`"light"`／`"rush"`／`None` |
| `place_straight(train, front, heading, frame=None)` | 直線：編成の親（`train.root`）を置く。`frame` を渡すとキーを打つ |
| `place_on_path(train, s_front, path, frame=None)` | 曲線：1両ずつ線路に沿わせる（台車中心2点を線の上に置き、勾配も入れる）。`path(s)` は弧長 s → 位置 |
| `path_from_curve(obj)` | Blender のカーブを `path(s)` の形にする（`f.length` が全長） |
| `set_linear(train)` | 毎コマのキーの補間を直線にする |
| `texts_to_meshes(train)` | 文字をメッシュに変える（フォントの無い環境へ渡す・書き出すとき） |
| `FORMATIONS` | 編成（新宿方からの車番、パンタ・電動車の位置）。dict を自分で渡してもよい |
| `KIND_COLORS` | 種別表示の文字色。ほかの種別は `kind_color=(R,G,B)`（sRGB 0〜1）で指定 |

Blender の画面で使うだけなら、`keio8000.blend` から「アペンド」（Collection → 編成名）するか、
アセットブラウザにこのファイルを登録して引きずり込む。行先などの文字は Blender 上で書き換えられる（フォント埋め込み済み）。

## 座標と約束（崩さない）

- 単位 m。**車両まわり：x＝車長方向、y＝左右、z＝レール面からの高さ（レール面＝0）**。
- 編成の親 `train.root`：原点＝先頭車の前端から 0.25m 先（連結器の先）、+x＝進行方向。
  車両 i（先頭から 0 始まり）の親は x = −(9.75 + 0.25) − 20.0·i。
- 先頭車・最後尾の車体は、運転台が編成の外側を向く（最後尾は Z 回り 180°）。
- 幕板の小物（側面の行先表示器・表示灯・車側灯・スピーカー・帯の切れ目）の並び：
  **車体の +y 面は u＝x、−y 面は u＝−x（どの車でも同じ）**。両側面の編成写真で確認した向き。
- 車番：中間車は新宿方の端、先頭車は運転台側の端。反対の端に KEIO ロゴ（両側面とも）。
- パンタグラフ：京王八王子方の台車の上（台座の中心が車両中心から 6.88m）、ひじは京王八王子方。
- 灯火：先頭車は前照灯、最後尾は尾灯。種別・行先の表示は先頭車だけ点く。
- 材質・メッシュの名前は `k8_` で始まる（使う側のデータと見分けるため）。

## 作業ルール（厳守）

### 1. チェックポイント方式
形・材質の数値を1回変えるごとに、次の3つを通してから先へ進む。**落ちたら先に進まない。**
```bash
python3 tools/verify_render.py /tmp/k8v            # 正射影2枚（2コアで約1分）
python3 tools/check_side.py /tmp/k8v/side.png      # 側面45項目 → PASS を保つ
python3 tools/check_front.py /tmp/k8v/front.png    # 前面14項目 → 12項目以上（外れる2項目は下の既知のもの）
```
前面で外れる2項目は写真の側の理由で、v4 の時点から同じ：
左の灯火ユニットの外端（写真が左右非対称、4cm）と、KEIO の K の赤い部分の形（写真の解像度では判別できない）。

### 2. 寸法の根拠は ref/keio8000_measured_v4.md
値を変えるときは、根拠（写真・資料と測り方）を同じファイルに書き足してから直す。

### 3. 見た目の確認は数値と画像で
「確認しました」で済ませず、照合のスクリプトを走らせるか、描いた画像を見る。

### 4. 推定の値を事実にしない
下の「確かでない点」は推定。資料で確かめるまで、確定した値として扱わない。

### 5. 本体の直し方
`keio8000/__init__.py` が本体（元は動画の build_scene.py と car_block_v4.py から、形と材質の数値を変えずに組み立てたもの）。
直すときは、変える箇所が想定どおりの回数だけ出てくるかを確かめてから置き換える（3d-keio と同じ厳密一致置換）。

## 確かでない点（推定）

- **8728F（8両）のパンタグラフの位置**：M車4両の京王八王子方に付けた。編成表の記号から推定したもので、写真では確認していない。
- **8713F の中間車の車番とパンタグラフの位置**：8714F にならった推定。
- **各停の種別表示の色（白）**：推定。特急（赤）・行先（橙）は v4 の値。
- 文字の書体は Noto Sans CJK JP Bold で、実車の LED や車番の書体とは違う。
- 扉は開かない（扉は車体の塗り分けとして描いている）。車内は簡略（床・壁・座席・つり革・照明・乗客）。
- 色は Cycles・AgX（Medium High Contrast）で合わせた。Eevee やほかのトーンマップでは見え方が変わる。

## 引き渡し時点の照合結果（2026-10-08）

- 側面45項目 PASS、前面14項目中12項目（外れ2項目は上の既知のもの）。
- 動画のモデル（keio.blend）と同じ位置に置いて描いた正射影との比較：
  画素の差の平均 0.009（側面）・0.003（前面）、最大 6/255（描画のノイズ）→ 同じ形・同じ材質。
- 曲線の例（examples/along_curve.py、R300m・25‰）：台車中心の線路からのずれ 0.0mm、車体の傾き＝勾配（1.43°）。
