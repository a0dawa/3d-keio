## ビューアでの扱い(4章 `KARA`・8章)

- 実データの道路と建物(plateau_land.js・plateau_bldg.js)があるときだけ(`KARA.on`)。無ければ以前の模式の円盤の広場
- 区域と 216 の帯の既存の建物・木は置かない(占有域 `KEEP` の 'p')。PLATEAU の道路・緑地の面は凸の穴(区域・帯の区間ごとの四角形)で
  切り抜き(`karaCut`・`convexMinus`)、切った片を `ROADS_PL` に登録し直す。216 の帯は幹線として `ROADS_PL` に足す
  (横切る道路の柱・歩道・車・街路樹は既存の仕組み)
- 地形は区域の中を平らに、外へ 30m で起伏へ(`TER.POLY`。以前は広場の点の周り 26m の円 `TER.DISC`)
- 航空写真は区域と帯の中は今の色(写真は今の建物・道路を写す)
- 建物は街の建物と同じ形と外装のシェーダ(低層部=タイルの茶・業務の連窓・1階は店、ピロティの棟=2〜3階、高層棟=RC の白・共同住宅・
  長い壁は5階から上がバルコニー)。ピロティの柱と天井・免震層・塔の下面・屋上の機械室・屋上の緑・バス停の上屋は別の1つの Mesh

## 検証(⑦ の 4g)

`tools/kara_ref.js` の値(このファイルから写した)で:区域・帯の中に既存の建物と木が無い・区域の中に既存の道路の面が無い・
216 の帯が道路の面で覆われる・柱が 216 の道路の縁から 1m 以上・区域の地形が 0・計画のビルの高さ(屋上 140m・低層部 16m・
免震層 21m)と階数(31・3)・塔の大きさ・広場の面が区域の中・木の本数・航空写真が区域の中で今の色。
