## p.20 の地表の読み方(2026-11。`RAW.kara.ground`)

1. 色で分ける:道路の灰 (198,204,204)±9・舗装のベージュ (227,210,194)±14・木の丸 (88,165,88)・点線の四角 (84,130,53)・淡い緑(緑が赤と青より 12 以上
   大きい。点線の四角の 5画素内・木の丸の 3画素内と、屋上の明るい緑・低層部の 1m 内は除く)・南側広場の円の中の木の色の大きな塊(植え込み)
2. 点線・文字・暈け・線・木の丸の画素は、最も近い既知の分類(車道・舗装・植え込み)で埋める。低層部と棟の足跡の中は舗装(地表は建物の下)
3. 図の上端の外(北東。区域の北の辺と桁の縁がそこまである)は舗装。線路沿いの道の口の北の隅切りだけ車道(半径 12m の円弧。**推定**)
4. 分類ごとに σ1.6 画素でぼかして最大を取り、4倍に拡大して輪郭(画素の中心)にする。車道は最も大きいつながりだけ(ロータリーと線路沿いの道。
   文字の縁などの小さな灰は舗装に)。2m² 未満の穴は埋める。計画の範囲で切り、0.08m で簡単にする
5. 舗装=範囲−車道。内外 2cm の膨らませで細い棘を消し、1m² 未満の片は車道に。植え込みは舗装の中の 6m² 以上・0.15m で簡単に
6. 輪は反時計回り、5cm 未満の隣の点と一直線の点を除き、原点 (35.6676, 139.6025) からの東・南の cm の差の列にする。HTML の耳切り(`earTri`)と
   同じ手順で三角形にして面積が合うことを確かめた(舗装 7片・植え込み 12片・木 66本。約5.7KB)

検証側の基準点(`tools/kara_ref.js` の `REF_ROAD`・`REF_PAVE`):上の 2〜6 を通さず、1 の色分けだけから、計画の範囲の 1m 内の 2.5m の格子の点で、
周り 7×7 画素(±0.5m)がすべて道路の灰か、すべて舗装のベージュの点(車道 352・舗装 169点)。

## ビューアでの扱い(4章 `KARA`・8章)

- 実データの道路と建物(plateau_land.js・plateau_bldg.js)があるときだけ(`KARA.on`)。無ければ以前の模式の円盤の広場
- 地表:車道(道路の 0.12m)を計画の範囲(区域+線路沿いの帯−216 の帯)の全体に敷き、舗装の板(0.27m)・植え込み(0.29m)を上に載せる
- 区域・線路沿いの帯と 216 の帯の既存の建物・木は置かない(占有域 `KEEP` の 'p')。PLATEAU の道路・緑地の面は凸の穴(区域・帯の区間ごとの四角形)で
  切り抜き(`karaCut`・`convexMinus`)、切った片を `ROADS_PL` に登録し直す。216 の帯は幹線として `ROADS_PL` に足す
  (横切る道路の柱・歩道・車・街路樹は既存の仕組み)
- 地形は区域の中を平らに、外へ 30m で起伏へ(`TER.POLY`。以前は広場の点の周り 26m の円 `TER.DISC`)
- 航空写真は区域と帯の中は今の色(写真は今の建物・道路を写す)
- 建物は街の建物と同じ形と外装のシェーダ(低層部=タイルの茶・業務の連窓・1階は店、ピロティの棟=2〜3階、高層棟=RC の白・共同住宅・
  長い壁は5階から上がバルコニー)。ピロティの柱と天井・免震層・塔の下面・屋上の機械室・屋上の緑は別の1つの Mesh(バス停の上屋は p.23 の鳥瞰に無いのでやめた)
